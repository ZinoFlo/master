# Security Policy

## Reporting a Vulnerability

The Eco-growth Discovery project team takes security seriously. If you believe you have found a security vulnerability in this project, please report it privately to the maintainers.

### Private Reporting Channels

Please use GitHub's [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-security-advisories/privately-reporting-a-security-vulnerability) feature to report any security concerns.

Alternatively, if private reporting via GitHub is not available, please contact the maintainer directly.

Do not create public GitHub issues for security vulnerabilities, as this may expose zero-day exploits to the public before a fix is available.
