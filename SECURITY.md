# Security Policy

## Reporting a Vulnerability

The security of this project is a top priority. If you believe you have found a security vulnerability, please report it privately.

**Do not open a GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities through one of the following channels:

1.  **GitHub Private Vulnerability Reporting:** If this repository is on GitHub, you can use the [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-a-vulnerability/reporting-a-vulnerability-to-a-repository-maintainer) feature to report the issue.
2.  **Email:** Contact the maintainer at [security@example.com](mailto:security@example.com) (replace with actual security email if available).

Please include as much information as possible in your report, including:

*   A description of the vulnerability.
*   The steps required to reproduce the vulnerability.
*   Potential impact if the vulnerability is exploited.

We appreciate your help in keeping this project secure.
