# Security Policy

## Supported Versions

Currently, only the latest version of the Eco-growth Discovery Add-in is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do **not** report it via a public GitHub issue. Instead, please use the following method:

### Private Vulnerability Reporting

The preferred way to report a vulnerability is through **GitHub Private Vulnerability Reporting**.

1. On GitHub.com, navigate to the main page of the repository.
2. Under the repository name, click **Security**.
3. In the left sidebar, under "Reporting", click **Advisories**.
4. Click **Report a vulnerability** to open the advisory form.
5. Fill in the advisory details and click **Submit report**.

Our security team will acknowledge receipt of your report and provide a timeline for addressing the issue. We ask that you follow [coordinated vulnerability disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure) and refrain from publicizing the vulnerability until it has been resolved.
