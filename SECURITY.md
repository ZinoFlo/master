# Security Policy

## Reporting a Vulnerability

The project team takes the security of our project seriously.
If you believe you have found a security vulnerability, please report it to us privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-reporting-vulnerabilities/reporting-a-vulnerability-in-a-repository) or by emailing the maintainers directly.

We will acknowledge your report within 48 hours and provide a timeline for addressing the issue.
