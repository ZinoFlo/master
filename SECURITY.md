# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it privately via GitHub Private Vulnerability Reporting.

To do this:
1. Navigate to the repository on GitHub.
2. Click on the 'Security' tab.
3. Click on 'Advisories' in the left sidebar.
4. Click 'Report a vulnerability'.

We will acknowledge your report and work to address the issue as quickly as possible. Please do not open a public issue for security-related concerns.
