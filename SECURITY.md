# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you find any security vulnerabilities, please do not report them via public GitHub issues.

### Private Reporting

Please report any security vulnerabilities via the **GitHub Private Vulnerability Reporting** feature for this repository. This allows us to communicate with you privately and work on a fix before public disclosure.

If the Private Vulnerability Reporting feature is unavailable, please contact the maintainers directly through their GitHub profiles.

### Disclosure Policy

We follow a coordinated disclosure process:
1. We will acknowledge your report within 48 hours.
2. We will investigate and provide an estimated timeline for a fix.
3. We will notify you once the fix is ready and coordinate the public disclosure.
