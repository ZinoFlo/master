# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it privately.

**Do not open a public GitHub issue for security vulnerabilities.**

### Private Reporting

Please use the [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/reporting-a-vulnerability-in-a-repository) feature to report vulnerabilities. This allows us to investigate and address the issue before it is made public.

If Private Vulnerability Reporting is not available, please contact the maintainer directly if a secure channel is provided.

### Process

1. You submit a report via GitHub Private Vulnerability Reporting.
2. Maintainers will acknowledge the report and investigate.
3. If confirmed, we will work on a fix.
4. Once a fix is ready, we will coordinate a release and public disclosure.
