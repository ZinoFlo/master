# Security Policy

## Supported Versions

Only the latest version of this repository is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it privately.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities via:
- **GitHub Private Vulnerability Reporting**: [Enable and use this feature if available in the repository](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
- **Direct Contact**: Please reach out to the project maintainers via their GitHub profiles to report vulnerabilities privately.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix.
