# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it immediately.

### Preferred Reporting Method

Please report vulnerabilities privately by emailing **security@example.com** or using the GitHub Private Vulnerability Reporting feature if enabled. Please do not open a public issue for security vulnerabilities.

### What to include in your report

When reporting a vulnerability, please provide the following details:
- **Vulnerability Type:** (e.g., XSS, SQL injection, insecure dependency)
- **Affected Version:** The version of the project where you found the issue.
- **Steps to Reproduce:** A clear, step-by-step description of how to reproduce the vulnerability.
- **Potential Impact:** A description of the potential impact of this vulnerability.

Thank you for helping to keep this project secure!
