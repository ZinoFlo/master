# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it privately.

**Please do not open a public GitHub issue for security vulnerabilities.**

### Private Reporting

The most secure way to report a vulnerability is via GitHub Private Vulnerability Reporting.

1. Go to the [Security tab](https://github.com/ZinoFlo/master/security) of the repository.
2. Select **Vulnerability reporting**.
3. Click **Report a vulnerability**.

### Disclosure Policy

We will investigate all legitimate reports and make every effort to quickly fix the issue. We ask that you follow the principles of responsible disclosure:

- Give us reasonable time to investigate and mitigate the issue before making any information public.
- Do not exploit the vulnerability further than necessary to prove its existence.

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
