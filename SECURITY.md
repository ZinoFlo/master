# Security Policy

## Reporting a Vulnerability

The Eco-growth Discovery team takes the security of our software seriously.

If you believe you have found a security vulnerability, please report it to us privately. You can do this by using the **"Report a vulnerability"** button under the **Security** tab of this repository on GitHub.

Please do not report security vulnerabilities through public GitHub issues.

### What to expect

After you submit your report, we will:
- Acknowledge receipt of your report within 48 hours.
- Provide an estimated timeframe for a fix.
- Notify you once the vulnerability has been resolved.

Thank you for helping keep Eco-growth Discovery secure!
