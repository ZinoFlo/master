# Security Policy

## Reporting a Vulnerability

The security of this project is a top priority. If you discover a security vulnerability, please do not open a public issue. Instead, please use the **Private Vulnerability Reporting** feature on GitHub.

To report a vulnerability:
1. Navigate to the repository on GitHub.
2. Click on the **Security** tab.
3. Click on **Vulnerability reporting** in the left sidebar.
4. Click **Report a vulnerability**.

By reporting vulnerabilities privately, you help protect the project's users and ensure that issues are resolved before they are publicly disclosed.

## Supported Versions

We only provide security updates for the latest stable version of this project.
